# Instalace nástrojů

Postup se liší podle operačního systému:

::::alternatives
:::option{label="macOS"}
Otevřete aplikaci **Terminal** a ověřte verzi Node.js:

```bash
node --version
```
:::
:::option{label="Windows"}
Otevřete **PowerShell** a ověřte verzi Node.js:

```powershell
node --version
```
:::
:::option{label="Linux"}
Otevřete terminál a ověřte verzi Node.js:

```bash
node --version
```
:::
::::

Očekávaný výstup vypadá přibližně takto:

```output
v24.0.0
```
