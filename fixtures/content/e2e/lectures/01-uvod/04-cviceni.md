# Cvičení: první prompt

Ve svém projektu zadejte agentovi prompt podle předchozí části. Výsledek ověřte
v prohlížeči. Odpověď níže je **nepovinná**.

```exercise
id: prvni-prompt-reflexe
revision: 1
title: Váš první prompt
fields:
  - id: prompt
    label: Použitý prompt
    guidance: Vložte prompt, včetně dalších pokusů.
  - id: vysledek
    label: Výsledek a ověření
    guidance: Co se stalo a jak jste to ověřili?
  - id: reflexe
    label: Reflexe
    guidance: Co fungovalo, co bylo obtížné a co příště uděláte jinak?
```
