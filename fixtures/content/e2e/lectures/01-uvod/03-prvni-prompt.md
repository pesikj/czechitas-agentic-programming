# První prompt

Dobrý prompt obsahuje cíl, kontext a způsob ověření.

| Část promptu | Příklad |
|---|---|
| Cíl | Přidej do stránky patičku s rokem. |
| Kontext | Stránka je v souboru `index.html`. |
| Ověření | Otevři stránku v prohlížeči a zkontroluj patičku. |

Příklad promptu pro agenta:

```prompt
Přidej do index.html patičku s aktuálním rokem. Nic jiného neměň.
```

- [x] Cíl je konkrétní
- [ ] Prompt obsahuje způsob ověření

Více o psaní promptů najdete na <https://docs.anthropic.com>.
